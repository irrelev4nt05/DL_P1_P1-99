# DL_P1_P1-99

Projeto P1 da unidade curricular de Deep Learning Aplicado.

## Problema

Classificação automática de imagens de resíduos utilizando redes neuronais
convolucionais (CNN).

O objetivo é classificar cada imagem numa de seis categorias:
- cardboard
- glass
- metal
- paper
- plastic
- trash

## Dataset

TrashNet, de Gary Thung e Mindy Yang.

O dataset contém 2527 imagens distribuídas por 6 classes.

As imagens da versão redimensionada têm resolução 512x384.
